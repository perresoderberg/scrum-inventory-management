# Inventory Management

# In order to run the Project

1. Open terminal
   npm run mock-server
2. Open another terminal
   npm run dev

## Project Structure

```text
app/            Next.js App Router pages and layouts
components/     React components grouped by feature
public/         Static assets
server/         Mock backend (json-server)
services/       API communication
styles/         Global or shared styles
types/          Shared TypeScript types
utils/          Helper functions
```

# Definition of Done

För vårt frontendprojekt är ett arbete **Done** när:

- Acceptanskriterierna är uppfyllda.
- Koden är färdig och begriplig.
- TypeScript kompilerar utan fel.
- ESLint har inga relevanta fel.
- Funktionen är testad.
- Funktionen fungerar tillsammans med resten av applikationen.
- Koden är mergad till gruppens gemensamma branch (inga merge-konflikter).
- Inga fel återstår.
- GitHub-issuet är uppdaterat (satt till **Done**).
