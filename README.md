# Inventory Management
 
Inventory Management is an admin dashboard for managing products in a webshop. The application is built with **Next.js**, **TypeScript**, and a mock API. The project is developed as part of a school assignment using **SCRUM**, GitHub Projects, feature branches, Pull Requests, and code reviews.
 
---
 
## Getting Started
 
### Prerequisites
 
- Node.js
- npm
 
### Installation
 
Install project dependencies:
 
```bash
npm install
```
 
### Run the project
 
Start the mock API:
 
```bash
npm run mock-server
```
 
Open a second terminal and start the Next.js development server:
 
```bash
npm run dev
```
 
Open your browser at:
 
```
http://localhost:3000
```

```
public/         Static assets (icons)
server/         Mock backend (json-server)
services/       API communication
styles/         Global or shared styles
types/          Shared TypeScript types
utils/          Helper functions
```

## Definition of Done
 
A task is considered **Done** when:
 
- Acceptance criteria are fulfilled.
- The code is complete and easy to understand.
- TypeScript compiles without errors.
- ESLint has no relevant errors.
- The feature has been tested.
- The feature works together with the rest of the application.
- The code has been merged into the shared branch without merge conflicts.
- No errors remain.
- The related GitHub issue is moved to **Done**.
